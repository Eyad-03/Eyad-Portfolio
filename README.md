# Eyad Mansur — Portfolio Website
Welcome to the official repository for my personal portfolio website (EYdiv). This platform showcases my professional background, technical skills, academic qualifications, and key projects as an ambitious Computer Science graduate and Full-Stack Developer.

🚀 Live Preview & Overview
The portfolio is designed with a modern, responsive dark-themed user interface, incorporating Bootstrap 5 and custom CSS styling to ensure a seamless experience across desktop, tablet, and mobile devices.

✨ Key Features
- **Responsive Navigation Bar**: Smooth scrolling across different sections (About me, Experience, Skill, Project, Qualification, Reference) with a dedicated "Contact us" action button.
- **Hero Section**: Quick introduction with social media links, downloadable CV access, and a live statistics counter tracking experience years, completed projects, and certificates.
- **About & Expertise**: Detailed bio outlining academic achievements and career aspirations alongside core focus areas (Software Development, Web Development, Web Design).
- **Interactive Skills Showcase**: Divided into technical competencies and soft skills with corresponding visual icons/badges.
- **Experience & Qualifications Timeline**: Showcasing professional internships (Al-Azima Company, Solution Development Kit, Orange Academy) and academic credentials (B.Sc. in Computer Science with an "Excellent" grade, Irbid 42 Piscine Certificate).
- **Featured Projects Grid**: Direct links to repositories for full-stack and front-end applications.
- **Professional References**: Contact references to validate professional collaborations.
